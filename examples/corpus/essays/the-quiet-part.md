Every evaluation that uses data the model has seen is a measurement of memory
dressed up as a measurement of ability.

## Holding something back

The discipline is trivial and almost nobody keeps it. Pick a piece before you
start, put it in the holdout list, and never look at it again until the run is
finished. One piece is thin evidence. Three, across different registers, is
enough to notice when a run has gone wrong.

The number you get is not meaningful in itself. It is meaningful against the
same number from last week, which is the only comparison that ever mattered.
